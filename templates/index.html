What is Python?

Python is one of the most popular and versatile languages in the world, ideal for both beginners and experienced professionals. Its simple and readable syntax allows learning programming naturally, while its versatility opens doors to areas like web development, data science, artificial intelligence, and automation.

With high demand in the job market and an active and welcoming community, Python offers excellent career opportunities. Its rich ecosystem of libraries and frameworks accelerates development, making it the perfect choice for those seeking productivity and relevance in today's technological landscape.

Syntax

Selection Structures

Selection structures control program flow based on conditions. In Python, we use if, elif and else to create logical decisions. These structures allow the program to execute different code blocks depending on true or false conditions. The syntax is simple and uses indentation to delimit code blocks. 

idade = 18
if idade >= 18:
    print("Adult")
elif idade >= 16:
    print("Can vote")
else:
    print("Minor")
# For loop
for i in range(5):
    print(f"Counting: {i}")

# While loop
contador = 0
while contador < 3:
    print(f"Repetition {contador}")
    contador += 1

Loop Structures

Python offers for and while loops to repeat operations. The for loop is ideal for iterating over sequences (lists, strings, ranges), while while repeats while a condition is true. We also have control commands like break (exit loop) and continue (skip to next iteration).

Arrays and Matrices

In Python, we mainly work with lists to represent arrays. Lists are dynamic structures that can store different data types. For matrices, we use nested lists (list of lists) or libraries like NumPy for more advanced mathematical operations. Lists support indexing, slicing, and various manipulation methods. 

# List (array)
frutas = ["apple", "banana", "grape"]
print(frutas[0])  # Access first element

# Matrix (list of lists)
matriz = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
print(matriz[1][2])  # Row 1, column 2
def saudacao(nome):
    return f"Hello, {nome}!"

def mostrar_info(nome, idade=25):  # Default parameter
    print(f"Name: {nome}, Age: {idade}")

# Calling functions
mensagem = saudacao("Maria")
print(mensagem)
mostrar_info("João", 30)

Functions and Procedures

Functions in Python are defined with def and can receive parameters and return values. They promote code reuse and modularization. Python doesn't formally distinguish between functions and procedures - a function that doesn't explicitly return a value returns None. They support default parameters, named arguments, and variable number of parameters.

Exception Handling

Exception handling uses try, except and finally blocks to capture and manage errors during execution. This allows the program to continue working even when problems occur, offering an elegant way to handle unexpected situations like division by zero, nonexistent files, or invalid data. 

try:
    numero = int(input("Enter a number: "))
    resultado = 10 / numero
    print(f"Result: {resultado}")
except ValueError:
    print("Error: Enter numbers only")
except ZeroDivisionError:
    print("Error: Cannot divide by zero")
finally:
    print("Operation completed")
